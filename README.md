## Data Availability

This repository provides a public sample of 300 aligned Chinese–Japanese aquaculture terminology pairs for research and reproducibility purposes. The full dataset contains 4,166 aligned entity pairs with term names, aliases, taxonomic information, and definition fields.

The full version of the dataset will be released after publication, subject to source license verification. Before full release, researchers may request access to the complete dataset from the corresponding author for non-commercial academic use.
